# REAL LIFE RPG — PWA прототип

Това е реален работещ PWA прототип, не само макет.

## Какво има
- 560+ мисии в базовия пул.
- 06:00–07:00: само Morning quests.
- 07:00–21:00: основният пул.
- 21:00–22:00: само Evening quests.
- След 22:00: няма нови нормални мисии.
- Всеки ден задачите се нулират, но XP/coins/статистики/историята остават.
- Само 1 активна мисия.
- 5 предложения чрез weighted random.
- Reroll лимит 3 на ден.
- XP, level, Discipline, Recovery, Coins, streak.
- Статус: Направих / Не направих / Не можах.
- Причини при „Не можах“, включително болест, семейна причина, училище, липсващи материали и време.
- При болест няма наказание; при липсващи материали има лек спад на Discipline.
- Някои мисии са маркирани за снимка.
- Локация чрез browser GPS.
- Времето се взема от Open-Meteo според координатите.
- Здравето се пита на всеки 3 часа.
- До 3 персонални задачи.
- 15 награди в магазина.
- Локално запазване на прогреса.
- Инсталира се като икона на Android чрез „Добавяне към началния екран“.

## Важно за пълната версия
Акаунти, сигурен cloud sync и AI трябва да минат през backend. Не слагай API ключ за AI директно в PWA клиента.
